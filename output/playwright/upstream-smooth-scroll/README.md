# Terminal smooth scrolling demonstration

A synthetic mouse-reporting terminal application captured in isolated Herdr windows. Left: smooth_scrolling=false. Right: smooth_scrolling=true at source commit 567f4936ddcd84d8b0b52087b7cc7a7c60d644ca.

The recording is cropped to the fixture terminal. It contains no real agent conversation, credentials, sidebar, working-directory paths or desktop content. Captured frames are shown at four times their original duration so fractional motion is visible; no intermediate motion frames were generated. Headers and composers remain fixed. Colours differ between the private capture profiles and are incidental to the scrolling comparison.

This is behavioral evidence, not a physical-device or production GPU/FPS benchmark.
